# 启动契约

`game/startup` 只保存跨命令或跨核心服务、且游戏运行前必须成立的契约。当前统一检查命令唯一性、数据库状态唯一归属和命令守卫引用；任一失败都会终止启动。

检查的具体实现只能放在 `contracts.py`，`__init__.py` 只导出公共入口。`game/app.py` 完成全部服务装配后只调用一次 `validate_startup_contracts()`，不得再次散落单项启动检查。

单个微服务自己的 JSON 字段、索引和运行数据校验仍归该微服务所有。代码目录、文件命名和命令 `scope` 是否与目录一致属于开发维护规范，其检查实现只能位于 `tools/架构审查` 并由维护者手动运行；测试可以调用正式检查入口，但不得复制规则。维护审查不得进入本目录或游戏启动流程。
