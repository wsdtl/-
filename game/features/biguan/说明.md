# 闭关组件

闭关固定 60 分钟，每满 10 分钟完成一轮。出关时按真实秒数线性恢复人物资源，并按完整轮次结算
人物经验和随机功法。表中只保存开始时间与随机种子；结算成功后删除会话。命令和守卫位于
`game/cmd/闭关`。

时间、经验、感悟概率和圆满清理规则从 `data/rules/修炼/修炼.json` 的 `闭关` 中文节点读取；
功法从 `data/content/物品/功法` 分类目录展开，通用品级来自 `data/rules/品级/品级-通用.json`，随机词条
来自 `data/content/战斗机制/词条.json`。

同行伙伴在同一出关事务中获得人物实际取得的经验，并按同一闭关时长比例恢复血气、精神和体力；圆满
闭关时与人物一起清除临时状态。伙伴恢复不复制第二套公式。
