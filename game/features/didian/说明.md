# 地点组件

`data/content/世界/青岚山境.json` 是单世界、坐标边界、地点坐标和当地功能的唯一配置。
`player_locations` 每名人物只保存一条 `x/y` 真实位置；地点坐标必须唯一且位于世界边界内。
配置使用 `世界`、`地点`、`出生地`、`坐标边界`、`坐标`、`可用功能`、`修士池` 和 `敌人池` 等中文字段。
两个资源池都填写一个或多个对应 JSON 文件名；地点组件在运行时把所引文件中的对象整合为一个候选池。
具体玩法触发遭遇时直接按对象权重从候选池抽取，不按文件分两次随机。权重越高，对象越稀有。
地点名直接作为地点 ID 和玩家命令参数，不经过翻译映射，也不把地点名写进人物位置记录。

人物可以即时前往任意已登记地点，移动距离按 `|横轴差| + |纵轴差|` 计算。玩家只会看到并发送
`前往 地点名称`；坐标用于地图展示、距离计算和持久化，不生成内部锚点命令。当前小循环不让距离
消耗体力或时间，后续增加交通规则时仍只能经过本组件修改人物位置。

地点组件不复制闭关或探险规则。闭关和探险在各自事务中读取当前位置，确认当地提供对应功能后
再开始；探险同时读取当地敌人池。活动期间先由命令守卫拦截移动，移动事务还会再次检查活动表，
避免并发命令把人物地点与活动状态拆开。
