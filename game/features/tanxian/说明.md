# 探险组件

探险开始时连续模拟最多六轮遭遇，只向玩家公开预计轮数。血气、精神、体力、护盾、临时状态、
冷却、主动招式轮转位置和丹药消耗跨轮继承；未获胜会终止后续模拟。结束时只结算已满 10 分钟的
轮次前缀。轮次状态保持精简，不保存完整战斗事件。命令和守卫位于 `game/cmd/探险`。

开始探险时锁定当时的同行伙伴。人物和仍有血气、体力的伙伴组成左方队伍，各自携带功法、本命武器、
附魔、宝石、状态、冷却和招式游标；丹药库存由整支队伍共享。每轮分别保存伙伴状态和体力，结算时校验
人物及伙伴资产修订号。胜利所得的本命武器经验同步发给人物和同行伙伴。

探险只读取当前位置 `敌人池` 所引用文件中的低阶灵兽。多个文件先整合成一个对象池，每轮遭遇再按
对象权重抽取，权重越高越罕见。灵兽等级、属性成长、实力波动和掉落来自 `data/content/敌人/灵兽`；探险通过敌人
资源组件生成通用参战快照，并在战斗外结算奖励，不另写敌方战斗规则。
敌对修士按流派保存在 `data/content/敌人/修士`，普通地点与探险不会引用；后续由秘境等独立玩法
组建战斗池。战利品生成时同时抽取品级，并以“品级 + 基础物品”完整对象结算进纳戒。
