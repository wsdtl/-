# 敌人资源组件

本组件把 `data/content/世界` 中紧邻地点的敌人池配置生成一次性参战对象。

- 敌对修士按地点放入同层敌人文件，复用人物每级成长，拥有本命武器、功法、纳戒和用药决定。
- 灵兽使用文件内的成长，只携带自身属性与固定掉落。
- 每名敌人的 `掉落.物品池` 直接引用物品 JSON；所引文件先合并，再按物品权重固定抽取一件并抽取品级。
- 本命武器不是物品，不进入纳戒、掉落或资产转移。
- 南部六州探险生成灵兽；镇岳防线及其以北生成敌对修士。
- 同层 `<地点>道侣.json` 不属于本组件，不能被生成敌人、结算掉落或独立用药。
- 场景选择、战斗执行和玩家奖励结算由调用它的玩法组件负责。
