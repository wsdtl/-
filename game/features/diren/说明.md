# 敌人资源组件

本组件把 `data/content/敌人/灵兽` 和 `data/content/敌人/修士` 中的配置生成一次性参战对象。

- 敌对修士按流派分文件，复用人物每级成长，拥有本命武器、功法、纳戒和用药决定。
- 灵兽使用文件内的成长，只携带自身属性与固定掉落。
- 每名敌人的 `掉落.物品池` 直接引用物品 JSON；所引文件先合并，再按物品权重固定抽取一件并抽取品级。
- 本命武器不是物品，不进入纳戒、掉落或资产转移。
- 普通地点与探险只引用灵兽；敌对修士留给后续秘境等独立战斗玩法。
- `data/content/角色/伙伴修士` 不属于本组件，不能被生成敌人、结算掉落或独立用药。
- 场景选择、战斗执行和玩家奖励结算由调用它的玩法组件负责。
