# 地点修士组件

本组件只读取提供“修士”功能地点的修士资料与话语。`<地点>道侣.json` 紧邻所属地点文件，文件中的
修士统一视为后续道侣候选；没有该功能的地点不配置道侣池。地点修士统一从 Lv1 开始。每名道侣直接在
同层 `<地点>道侣.json` 中定义修行方向、资质范围，并各引用一个专属功法、附魔和宝石 JSON，不逐个抄写对象名，也
不允许退回全内容池。道侣候选文件不接受功法、本命武器、战斗策略、纳戒或掉落字段，不能被生成为
敌人式战斗快照。

功法、附魔和宝石文件直接展平在各自物品目录。每份专属 JSON 包含 9 项候选，道侣分别从中抽取三项；
不同道侣之间没有相邻关系，也不跨文件共享候选池。

本组件同时负责赠礼偏好、好感、一次性回礼、入队和离队。道侣首次入队时一次生成并持久化方向、资质、
本命武器、三门功法、三个附魔和三颗宝石；离队只改变同行关系，返回原居地点，再次入队不会重抽资产。

每名道侣通过 `喜爱天材地宝池` 直接引用一个任意地形的天材地宝 JSON，不受原居地点限制。引用池展开后的
全部物品都可赠送并增加好感，池外物品一律拒收，且不会从人物纳戒扣除。

同行道侣作为独立参战者进入探险，使用自己的资源、状态和装配，与人物共享纳戒丹药；闭关时获得人物
实际获得的经验，并按相同比例恢复血气、精神和体力。道侣没有独立纳戒、独立掉落或第二套恢复公式。
