# 地点修士组件

本组件只读取提供“修士”功能地点的修士资料与话语。`data/content/角色/伙伴修士` 按地点分文件，文件中的
修士统一视为后续伙伴候选；没有该功能的地点不配置修士池。地点修士统一从 Lv1 开始，并显式引用一个或多个
`方向-*.json` 文件。
方向继续通过功法、附魔和宝石的完整 JSON 文件名限定候选，不逐个抄写对象名，也
不允许退回全内容池。伙伴候选文件不接受功法、本命武器、战斗策略、纳戒或掉落字段，不能被生成为
敌人式战斗快照。

本组件同时负责赠礼偏好、好感、一次性回礼、入队和离队。伙伴首次入队时一次生成并持久化方向、资质、
本命武器、三门功法、三个附魔和三颗宝石；离队只改变同行关系，返回原居地点，再次入队不会重抽资产。

同行伙伴作为独立参战者进入探险，使用自己的资源、状态和装配，与人物共享纳戒丹药；闭关时获得人物
实际获得的经验，并按相同比例恢复血气、精神和体力。伙伴没有独立纳戒、独立掉落或第二套恢复公式。
