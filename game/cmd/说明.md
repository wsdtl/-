# 命令层

`game/cmd` 只负责把玩家输入转换为玩法调用和协议中立回复。二级玩法组件使用中文目录；跨组件共享的命令基础设施使用英文文件名，业务代码不得导入其他中文组件目录。

## 公共基础设施

- `command.py`：统一封装 `fullmatch`、`command`、`regex` 三种注册器，同时登记访问级别、人物状态准入规则和帮助。
- `access_guard.py`：从公共消息上下文取得稳定用户编号，调用 `core/activity` 完成人物状态准入判断。
- `help_registry.py`：保存命令注册时声明的公开帮助，不读取数据库或游戏 JSON。

公开命令必须提供 `HelpSpec`，内部命令必须使用 `hidden=True`。玩家命令默认引用人物状态规则 `仅空闲`；确实不受人物状态影响的公共入口必须显式使用 `activity_rule=None`。

命令层不得直接读写 SQLite，不得解释人物状态 JSON，也不得把 QQ 私有事件对象传入核心或玩法微服务。
