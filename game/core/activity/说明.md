# 异步玩法公共生命周期

本核心只解释玩法已经保存的阶段、开始时间、结束时间、完成时间、参与者和结算权限，统一返回`pending`、`running`、`ready`、`settled`或`terminated`。它不保存会话，不读取具体玩法 JSON，也不代替探险、闭关或宗门战执行结算。

具体玩法仍各自拥有会话正文和结果：探险按场次解封且到时才可结算；闭关允许发起者按完整轮次提前出关；宗门战只有正式开战后才进入计时。进程重启后，各玩法从 SQLite 重新读取自己的事实，再交给本核心解释，不依赖内存定时器恢复状态。

所有时间必须携带时区。剩余时间只用于展示和守卫判断，不能据此重新生成战斗、奖励或功法感悟。
