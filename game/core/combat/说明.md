# 战斗核心微服务

`game.core.combat` 是第二个核心公共微服务。它不自行读取文件，也不拥有角色资产；初始化时消费已经完成加载的 `JsonDataService`，并负责解释战斗基石以及功法、附魔、宝石对战斗的影响。

```text
CoreServices.data
  -> load_battle_foundation(data)
  -> BattleEngine / DamageEngine / MechanismRuntime
  -> CombatService
  -> CoreServices.combat
```

战斗定义来自：

- `定义/战斗/属性.json`
- `定义/战斗/资源.json`
- `定义/战斗/事件.json`
- `定义/战斗/原子能力.json`
- `规则/战斗/伤害.json`
- `规则/战斗/行动.json`
- `规则/战斗/状态反应.json`
- `内容/战斗机制/*.json` 经 `core.data` 编号索引后展开
- `展示/战报.json`

其他业务只能从 `game.core.combat` 包顶层使用 `CombatRequest`、`CombatantSpec`、`CombatBuildRef`、`CombatResult` 和 `CombatService`。`engine.py`、`models.py`、`mechanics.py` 等均为内部实现。

```python
result = await combat.execute(
    CombatRequest(
        left_team=(player,),
        right_team=(enemy,),
        seed=123,
        action_limit=2000,
    )
)
```

`CombatantSpec.build` 只携带功法、附魔和宝石的稳定编号与实例信息，战斗服务自行通过数据服务解析定义。战斗核心只处理行动条、技能冷却、事件、监听、状态、伤害、召唤、构造物和战报事实，不创建角色资产，也不参与评分和平衡。
