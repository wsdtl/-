# 战斗核心微服务

`game.core.combat` 是第二个核心公共微服务。它不读取文件，也不拥有角色、功法、附魔或宝石资产；初始化时只消费已经完成加载的 `JsonDataService`。

```text
CoreServices.data
  -> load_battle_foundation(data)
  -> BattleEngine / DamageEngine / MechanismRuntime
  -> CombatService
  -> CoreServices.combat
```

战斗定义来自：

- `定义/战斗/属性.json`
- `定义/战斗/资源.json`
- `定义/战斗/事件.json`
- `定义/战斗/原子能力.json`
- `规则/战斗/伤害.json`
- `规则/战斗/行动.json`
- `规则/战斗/状态反应.json`
- `内容/战斗机制/*.json` 经 `core.data` 编号索引后展开
- `展示/战报.json`

`cmd` 只能调用 `current_game_services().core.combat`，不能导入引擎内部模块。战斗核心只处理行动条、技能冷却、事件、监听、状态、伤害、召唤、构造物和战报事实，不创建角色资产，也不参与评分和平衡。
