# 宗门战核心

宗门战核心拥有战书共享实体，管理约战、应战、退款、锁阵、开战、到时结算和历史记录。正式开战时一次完成真实战斗并保存不可变战果与战报，120秒只负责延后开放结算，不会在进程中持续计算战斗。

战斗完成后的角色资源、宗门灵石、参战者状态释放和战书终态按公共结算计划在一笔数据库事务中提交。任何版本冲突都会整笔回滚；相同请求编号只能重放同一事务。

双方人物和道侣的长期伤势随战前构筑装配。战后只接受对方施加且仍存续的登记负面状态，并结合角色自身境界异状生成最终伤势；伤势快照写入战果，在计时结束时与人物资源及宗门奖励原子结算。

进程重启后，服务从 SQLite 读取战书的开始时间、结束时间、参战者和战果，再通过异步生命周期核心恢复`running`或`ready`。不使用内存定时器，不重新执行战斗，也不重复消耗战丹、恢复丹或阵法。
