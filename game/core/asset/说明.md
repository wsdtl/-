# 玩家资产核心微服务

本服务把数据库中的玩家资产状态与正式 JSON 实体组合成只读视图，供纳戒等玩法查询。它只解释 `inventory`、`cultivation_library`、`law_reserve`、`formation_reserve` 和 `knowledge`，不执行服丹、换装、覆炼、布阵、炼药或炼器。

普通物品、道藏、器藏、阵藏和所学的显示顺序、小类依据、排序方向与每页上限只读取 `data/展示/纳戒/分类.json`。名称、品级、器阶和编号类别来自 JSON 数据微服务；数据库不保存这些重复分类。

本服务可以读取 `cultivation/main` 标记道藏中已经装配的功法、真意和气机，但不拥有修行槽写权限。后续资产变更必须由对应领域服务通过核心数据库事务提交。
