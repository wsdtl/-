# 玩家位置核心微服务

本服务是所有玩家地表 `xy` 的唯一事实源。位置保存在 `player_location`，角色资产不再重复保存坐标；地点、区域、地形和海拔始终交给世界核心按 `xy` 推导。

创建人物通过 `initial_mutation()` 把初始位置与人物资产放入同一数据库事务。单人行路和队长带队行路都通过位置版本执行乐观并发更新；`move_many()` 要求所有同行者仍在同一地表出发坐标，并在一次事务中同步全部玩家位置。`player_space`保存地表或宗门洞天，空间切换与坐标版本在同一事务完成；洞天内禁止世界行路。附近查询在数据库层同时按 `(x, y)` 与空间筛选，再根据世界地势推导的海拔差执行三维距离过滤，避免不同空间相同坐标互相可见；它不读取人物资产，也不解释队伍、道侣或敌人。

秘境、闭关空间和战斗空间属于具体玩法状态，不覆盖地表位置。附近修士的公开资料、状态过滤、本地修士合并和分页由 `features/weizhi` 组合其他核心服务完成。
