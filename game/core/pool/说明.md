# 资源池核心微服务

`game.core.pool` 是第三个公共核心微服务。它消费 `JsonDataService` 已经建立的内容分组和编号实体索引，不自行读取 JSON。

支持两种正式模式：

- `允许重复`：保留不同池对同一实体的重复引用，每次抽取后放回候选，可重复命中。
- `展开去重`：先按实体编号合并候选，抽取后移出候选，单次结果不重复。

所有候选必须在自身 JSON 定义中提供正整数 `权重`。抽中概率与 `1 / 权重` 成正比，因此数值越高越稀有。随机种子随结果返回，同一数据快照、参数和种子必须得到同一结果。

```python
from game.app import current_game_services
from game.core.pool import EXPAND_DEDUPLICATED

result = current_game_services().core.pool.draw(
    file_ids=("功法-剑诀", "功法-雷法"),
    section="功法",
    count=6,
    mode=EXPAND_DEDUPLICATED,
    seed=123,
)
```

`features` 负责决定为什么抽、抽哪个池和结果归谁；`PoolService` 只负责稳定展开、权重裁决和可复现抽取。
