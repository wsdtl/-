# 世界微服务

`WorldService` 是世界、区域、地点、地势与道路 JSON 的唯一代码解释者。

- `(x, y)` 唯一定位地表位置，海拔只由地势取得。
- 已登记地点既可以按地点名查询，也可以按精确 `(x, y)` 查询。
- `region_at(x, y)` 返回二维坐标所属区域；`terrain_at(x, y)` 只按区域地形分区解析。
- 区域 JSON 的 `地形分区` 必须完整、不重叠地覆盖区域，地点不再重复保存地形。
- `地势.json` 独占 `0..99` 坐标边界、水平尺度和海拔范围，世界与区域不复制这些派生事实。
- 地点不保存或接受独立 `z` 坐标。
- 区域归属由二维范围唯一确定，并在启动时校验。
- 服务只提供世界事实，不保存人物当前位置或行程进度。
- 其他服务只能从包顶层使用不可变公共契约。
