# 世界地点服务

世界地点服务只负责把正式 JSON 中的世界定义解析成地点查询结果。

- `LocationQuery.location_name`：按地点名查询，返回地点声明的可用功能、派生资源池和单次遭遇数量。
- `LocationQuery.xy`：按 `xy` 查询，返回区域、地形和地表海拔；坐标不在命名地点时，视为野外地表。
- 地表海拔只从 `data/内容/世界/地势.json` 读取，坐标范围由同一文件声明。
- 地形从区域的 `地形分区` 按坐标计算，不在地点文件中重复保存。
- 灵植池和灵矿池由地形名称派生；道侣池和敌人池由地点功能及同目录同名内容文件派生。
- 服务不保存玩家位置、不规划行程，也不触发探险、修士或战斗。

公开调用只经过 `game.core.world` 包顶层，业务命令不读取世界 JSON 内部结构。
