# 角色核心微服务

角色服务解释 `data/规则/角色`、`data/定义/角色`、战斗属性、境界、初始炼器规则，并拥有玩家角色资产的创建写入权限。玩家的行为、队伍和控制状态由 `game/core/player_state` 独立解释和变更。

创建人物是一笔数据库事务，写入 `character/main`、`cultivation/main`、`weapon/main`、`player_state/main` 和初始丹药背包状态。服务只接收稳定用户编号、创建输入和出生地 `xy`，不读取命令文本，也不直接访问 JSON 文件系统。

`profile(user_id)` 一次读取该用户的全部状态快照，严格解释人物、修行槽、本命武器和背包摘要。缺少创建事务应当写入的任一主体状态时直接报错，不使用代码默认值补造人物资产；地点和行为、队伍、控制状态仍由玩法层分别向世界与玩家状态服务取得。
