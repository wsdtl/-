# JSON 数据核心微服务

`game.core.data` 是核心微服务层的第一个正式成员。它在进程启动时读取一次 `data`，建立只读文档、分组和编号实体索引，并向 `features` 中的玩法微服务提供定义数据。

```text
game/app.py
  -> CoreServices.data
  -> JsonDataService.initialize()
  -> JsonDataReader 严格解析 JSON
  -> GameDataLoader 建立路径、分组和编号索引
  -> FeatureServices 中的玩法微服务通过构造参数取得依赖
```

`cmd` 是触发层，只能通过 `current_game_services()` 取得已经装配完成的服务，不得自行创建 `JsonDataReader` 或直接导入 `game.core.data`。

```python
from game.app import current_game_services

data = current_game_services().core.data
technique = data.entity("功法", "400001")
all_gems = data.entities("宝石")
pool = data.expand_pool(["物品-宝石-命闪"], "宝石")
```

运行期间不扫描、不监听、也不重新加载 JSON。修改正式数据后必须重启服务。完整校核、评分和平衡仍属于 `tools`。
