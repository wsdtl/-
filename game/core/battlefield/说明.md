# 战场环境微服务

`BattlefieldService` 把地点名、任意地表 `xy` 或秘境场景转换为战斗核心的 `CombatFieldSpec`。

- 地表战斗的 `xy` 由 `WorldService` 校验；所有坐标统一使用区域地形分区，海拔继续由世界地势计算。
- 秘境没有地表 `xy` 和海拔，不使用 `(0, 0)` 等虚假坐标。
- 秘境未指定专属环境时使用环境规则登记的无相境；无相境没有入阶能力和常驻能力。
- 服务只投影战场环境的编号和名称，不保存阶段、能力等战斗正文。
- 服务不保存人物当前位置，不读取数据库，也不执行伤害和阶段变化。
- 战斗核心独占环境 JSON 的解析、校验和阶段执行；无相境的“完全无效”约束也只在战斗核心校验。

## 位置与执行边界

```text
地点名或任意 xy
  -> WorldService 解析区域、地形分区和海拔
  -> BattlefieldService 按地形选择环境编号
  -> CombatFieldSpec
  -> CombatService 执行环境阶段
```

`BattlefieldService` 不计算承伤、不推进阶段、不保存人物位置。地点业务传入人物当前地点名或精确 `xy`；秘境业务传入场景名与可选环境编号。
