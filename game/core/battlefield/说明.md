# 战场环境微服务

`BattlefieldService` 把登记地点、精确地点坐标或秘境场景转换为战斗核心的 `CombatFieldSpec`。

- 地表战斗的 `xy` 只能来自 `WorldService` 已登记地点；海拔继续由世界地势计算。
- 秘境没有地表 `xy` 和海拔，不使用 `(0, 0)` 等虚假坐标。
- 秘境未指定专属环境时使用环境规则登记的无相境；无相境没有入阶能力和常驻能力。
- 服务不保存人物当前位置，不读取数据库，也不执行伤害和阶段变化。
- 战斗核心只接收环境编号与战场事实，并自行解析、校验和执行环境 JSON。

## 位置与执行边界

```text
地点名或精确 xy
  -> WorldService 解析登记地点、海拔和地形
  -> BattlefieldService 按地形选择环境编号
  -> CombatFieldSpec
  -> CombatService 执行环境阶段
```

`BattlefieldService` 不计算承伤、不推进阶段、不保存人物位置。地点业务传入人物当前地点名或精确 `xy`；秘境业务传入场景名与可选环境编号。
