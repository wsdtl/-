# 玩家状态核心微服务

本服务解释 `data/规则/角色/状态` 中的行为、队伍、控制、初始组合与状态守卫。数据库只保存一份 `player_state/main` 快照；快照保存状态编号和业务上下文，状态名称始终从当前 JSON 解析。

三个状态槽可以同时存在。例如玩家可以处于“探险中 + 组队中 + 托管中”。守卫对不同类型执行“并且”，同一类型的多个允许状态执行“或者”，没有声明的类型不参与判断。

创建人物时，角色服务把 `PlayerStateService.initial_mutation()` 并入同一事务。具体玩法通过本服务变更状态并提交数据库版本；命令守卫只读检查，不能代替玩法事务中的版本校验。
