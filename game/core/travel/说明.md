# 行程微服务

`TravelService` 使用世界微服务交付的二维地表、道路、地形和海拔事实，按 JSON 规则自动选择路线。

- 依次按折算路程、道路段数、水平距离选择最优路线。
- 起点与终点可以使用正式地点名、任意 `(x, y)`，或由其他业务提供的 `TravelEndpoint`。
- 任意坐标都可以在地形上行走；正式道路只是更换对应坐标边的通行倍率。
- 道路默认双向，上升和下降按实际行进方向分别计算。
- 行程输出道路段、地形段、结构化指标、完整地表剖面和 JSON 驱动的叙事文本。
- 境界目前没有速度或措辞规则，服务不会在代码中自行补默认值。
- 服务不修改人物位置，也不保存行程状态。
