# 游戏外工具边界

`tools/` 负责正式游戏之外的开发辅助工作：内容生成、全库校核、评分计算、平衡模拟和维护报告。

## 依赖方向

```text
tools -> data
tools -> game（只复用纯战斗模拟或数据模型）
game -X-> tools
```

游戏进程不得导入本目录模块，不得读取 `tools/战斗校验/`，也不得在启动、抽取、战斗、结算或展示过程中计算评分和方向平衡。

## 战斗校验

旧方向评分模型与现行全局实体库不兼容，其脚本和配置已删除。新平衡体系建立前，
`tools/` 不提供任何可能被误认为现行规则的评分结果。当前内容结构和战斗语义由自动化测试守卫。

工具输出只写维护报告，不写回正式 JSON、玩家数据库或游戏实例。评分结果只能帮助维护者调整正式规则数值，不能成为游戏实体字段、玩家展示数据、随机权重、价格、存档或战斗公式。

游戏仍可在读取实际所需文件失败、引用的实体不存在或玩家输入不满足玩法前置条件时拒绝执行；这是运行失败处理，不是全库校核。完整内容是否可发布，只由本目录工具判断。

`战斗校验/校验全池权重.py` 只读检查功法、附魔和宝石的实体权重、名称关系及全局唯一性，同时确认城镇道侣不再携带随机遭遇权重。
