# 天材地宝 JSON 关系说明

天材地宝是按地形和产地组织的普通物品池，使用 `20` 前缀编号。当前 54 个文件、108 个实体。

## 主要引用

```text
地点.天材地宝池 ----------------> 本目录文件名
道侣.结交.喜爱天材地宝池 ------> 本目录文件名
敌人.掉落.物品池 --------------> 可引用本目录文件名
```

地点和道侣引用的是文件池，不是固定物品编号。多个池应先展开合并，再按实体权重抽取。

天材地宝目前没有 `使用效果`，主要承担采集、掉落、赠礼和交易候选。未来若增加炼丹或炼器用途，应由新的配方或用途 JSON 引用天材地宝编号，不能把用途硬编码进名称。

## 修改检查

- 编号必须使用 `20` 前缀，`类别` 必须是天材地宝。
- 改池文件名时必须检查全部地点、道侣喜好和敌人掉落。
- 权重只影响池内抽取，不参与物品强度和价格计算。
- 同一实体若进入多个地形池，编号和完整定义必须一致。
