# 修行器物 JSON 关系说明

修行器物是服务人物培养或关系培养的可堆叠普通物品，使用 `30` 前缀编号。当前 3 个文件各保存 1 个实体。

## 关系

```text
增加人物经验 -> 规则/角色/修士修炼.json.经验
增加本命武器经验 -> 规则/角色/本命武器.json.经验
关系类使用效果 -> 规则/角色/道侣.json 与未来结交业务
```

物品只声明效果和数值，不直接修改数据库。未来业务负责校验目标、消费数量、执行事务并落账。

## 修改检查

- 编号必须使用 `30` 前缀，`类别` 必须是修行器物。
- 效果类型必须有明确通用消费者，不能依赖说明文字。
- 经验数值与品级倍率的关系必须统一，不能在命令层另写倍率。
- 关系类器物必须明确作用目标，避免把道侣名称当稳定数据库身份。
