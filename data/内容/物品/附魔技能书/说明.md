# 附魔技能书 JSON 关系说明

附魔是本命武器上的被动战斗对象，使用 `41` 前缀编号。当前 20 个分类池、600 个附魔。

## 结构关系

```text
附魔实体
-> 一个被动技能
-> 一个引用被动机制节点
-> 内容/战斗机制中的监听机制
```

附魔没有主动技能，不形成完整功法循环。被动技能与监听节点必须符合 `定义/战斗/原子能力.json`，所监听事件必须存在于 `定义/战斗/事件.json`。

## 与其他 JSON 的关系

- `规则/成长/本命武器.json -> 附魔位` 决定武器可装配数量；
- `规则/战斗/构筑.json` 决定全局装配上限和机制相冲；
- `定义/品级.json` 为附魔实例提供独立品级；
- 未来角色或掉落池通过 `物品-附魔-*.json` 文件名引用候选池。

附魔不保存评分、权重、方向、兼容标签或随机词条。

## 修改检查

- 编号必须使用 `41` 前缀。
- 根能力必须是被动技能，机制引用必须指向有效被动监听机制。
- 修改监听机制会影响所有引用该机制的附魔和功法。
- 新增附魔不能靠改名复制已有实际能力。
