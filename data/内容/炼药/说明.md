# 炼药内容关系说明

本目录保存丹方和炼药专用药引池。丹药实体仍属于普通物品，放在 `内容/物品/丹药`；108 株灵植和全部兽宝继续保留各自的掉落池，不为炼药复制实体定义。灵矿暂不参与炼药。

```text
药引/药引-兽宝.json
  -> 展开 122 个灵兽兽宝池
  -> 得到 366 个可用兽宝编号

丹方/恢复丹/*.json、丹方/战丹/*.json、丹方/突破丹/*.json
  -> 药引池：药引-兽宝
  -> 炉法：规则/炼药/炉法.json
  -> 成丹：内容/物品/丹药/*/*.json
```

`药引-兽宝.json` 是源池列表，不重复写 366 个编号。新增灵兽及其兽宝时，需要把新的 `兽宝-<灵兽名>` 文件名加入该池；一个池内的三项兽宝会由 JSON 数据微服务递归展开。

丹方按用途使用稳定编号：恢复丹方 `11`、战丹方 `13`、突破丹方 `15`、特殊丹方 `17`。丹方中的药引候选范围保存池文件名，选定入炉后使用兽宝编号；成丹直接保存丹药编号。战丹丹方按战丹方向拆分文件，突破丹方按境界节点拆分，特殊丹方按长期成长和构筑流程拆分，最低材料品级由炼制难度规则统一推导，不在每张丹方重复保存。丹方名称可以修改，编号不可修改。

## 修改检查

- 每张丹方必须引用一个已登记药引池、一门已有炉法和一个已有丹药编号。
- 战丹丹方的强度必须与成丹一致，炼制难度必须符合对应炉法味数。
- 药引池只能引用兽宝源池，不能混入灵植或丹药。
- 全部兽宝都应通过药引池可达；全部灵植都应通过归脉关系参与至少一门炉法。
- 丹方不保存具体辅材清单、评分、平衡记录或业务执行状态。
