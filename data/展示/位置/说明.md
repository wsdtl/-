# 位置展示

位置展示把已经完成范围过滤的位置事实组织为`位置`和`附近`回复。

```text
玩家地表 xy
+ 世界核心推导的地点、区域、地形与海拔
+ 地点事实中的可用功能
+ 展示规则允许公开的功能
+ 范围内的动态修士和当前地点的道侣
+ 规则/距离与方向.json
+ 规则/{文本,图标}.json
+ 按钮/{位置,附近}.json
-> 当前位置、附近概览、修士分页和地点列表
```

地点 JSON 的 `可用功能` 是世界事实；`规则/开放功能.json` 是当前对玩家开放的展示白名单。位置和附近输出只展示两者的交集，不由代码补写或默认开放。

## 文件职责

| 文件 | 职责 |
| --- | --- |
| `规则/距离与方向.json` | 里数折算、同处措辞和八方向名称 |
| `规则/文本.json` | 回复栏目名称、空状态和组合模板 |
| `规则/图标.json` | 回复栏目使用的消息图标 |
| `按钮/位置.json` | 当前位置页面的固定动作 |
| `按钮/附近.json` | 附近概览、分页、地点页和动态行路动作 |

本目录不改变`规则/位置/附近.json`中的查询半径、候选上限、公开状态或分页数量。本地修士来自世界道侣定义，动态修士来自角色公开摘要，二者不能互相替代。

修改方向或距离单位时检查八方向完整且与行程距离尺度一致；修改文本或按钮时初始化位置玩法，检查模板占位符、页面、条件、行为、样式和动作编号。
