# 成长规则关系说明

本目录把“角色是谁”和“角色怎样升级”分开。世界内容只声明角色类型和使用哪条成长规则，具体成长数值统一在这里维护。

## 修士成长

`修士.json` 被以下对象共同引用：

- `规则/初始/人物.json` 创建的玩家；
- 世界道侣中的 `成长规则: 修士`；
- 标记为修士的敌人。

属性建立顺序：

```text
定义/战斗/属性.json 默认值
-> 角色自己的属性覆盖
-> 从起始等级开始累计 修士.json.属性成长.每级
-> 道侣实例额外使用 规则/道侣.json 的资质成长倍率
```

属性名必须来自 `定义/战斗/属性.json`。灵兽若在敌人内容中保存 `每级成长`，不使用修士每级成长，但仍使用同一属性定义。

## 本命武器成长

`本命武器.json` 定义武器等级、基础攻击、每级攻击、经验公式以及附魔位和宝石位。它与以下内容关联：

```text
本命武器攻击 -> CombatantSnapshot.weapon_attack -> 战斗伤害
附魔位       -> 内容/物品/附魔技能书
宝石位       -> 内容/物品/宝石
交锋所得     -> 世界敌人.交锋所得.本命武器经验
```

本命武器不是普通物品，不使用物品编号，也不进入普通物品池。

## 修改检查

- 修改修士成长会同时影响玩家、道侣和敌方修士。
- 修改武器槽位时同步检查 `规则/战斗/构筑.json` 的装配上限。
- 修改经验参数时确认未来业务对“当前等级到下一级”的公式解释一致。
- 属性成长只能引用已登记属性，不能在成长文件中创造新属性。
