# 炼药规则关系说明

炼药只遵循一条主线：兽宝为引，灵材为辅，循药脉、行炉法、依丹方成丹。丹方不逐项罗列具体灵材，避免把炼药退化成重复填表。

## 四层规则

```text
归脉.json：灵材池 -> 本脉 + 旁脉
炉法.json：炉法 -> 所需药脉与味数
丹则.json：本脉取材、旁脉替代、成丹与战丹时限
战丹.json：战丹强度、丹位、炼制难度、辅材味数与最低品级
```

五条药脉分别是：

| 药脉 | 丹道取向 |
| --- | --- |
| `青华` | 生发、续养、复苏 |
| `丹离` | 催化、激发、炼化 |
| `坤载` | 承载、镇固、调和 |
| `太白` | 凝练、锋锐、收束 |
| `玄冥` | 润养、潜藏、沉静 |

每个灵材池只登记一次本脉和一次旁脉。炉法需要某条药脉时，本脉灵材一味占一位；旁脉灵材两味代一位，并且每炉至多旁脉替代一次。同一味灵材不能同时占多个炉位。

炉法集中保存辅材结构。丹方只保存药引池、炉法和成丹编号，因此同一兽宝可以随不同炉法炼成不同丹药，新增灵材也只需要补一次归脉关系。

战丹强度衡量下一场战斗收益，决定丹位；炼制难度衡量药性调和复杂度，决定炉法味数与最低材料品级。两者不是同一尺度，同强度可以有不同炼制难度，但必须落在 `战丹.json` 允许的组合内。

## 战丹时限

战丹服下后先寄存在人物状态中，只在下一场正式战斗开始时转成 `战前状态`。正常结算后清除；测试战斗不生效，中止战斗不消耗。战斗核心只接收已经装配好的状态，不读取丹方、纳戒或炼药业务。

## 修改检查

- 54 个地形灵材池必须在 `归脉.json` 中各出现一次，不能遗漏或重复。
- 炉法只能引用 `青华`、`丹离`、`坤载`、`太白`、`玄冥`。
- 丹方的药引池必须能展开为兽宝，炉法必须存在，成丹编号必须存在。
- 丹方强度必须与成丹一致；炼制难度必须匹配炉法辅材总味数和最低品级。
- 炼药业务以后只消费 `炼药规则`、`丹方`、`药引池`、`灵材`、`兽宝` 和 `丹药` 数据集。
