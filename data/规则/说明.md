# 规则 JSON 关系说明

`规则` 保存跨实体复用的计算方式和流程参数。规则不枚举具体人物、地点、功法或物品。

## 分区

| 目录或文件 | 负责内容 | 详细说明 |
| --- | --- | --- |
| `初始/人物.json` | 新人物的初始等级、属性覆盖、资源和物品 | [初始/说明.md](初始/说明.md) |
| `成长/修士.json` | 玩家、道侣、敌方修士共用的等级成长 | [成长/说明.md](成长/说明.md) |
| `成长/本命武器.json` | 本命武器等级、攻击和槽位 | [成长/说明.md](成长/说明.md) |
| `修行/闭关.json` | 闭关时长、轮次和收益参数 | [修行/说明.md](修行/说明.md) |
| `修行/探险.json` | 探险轮次、战斗上限和用药阈值 | [修行/说明.md](修行/说明.md) |
| `道侣.json` | 好感、同行槽位和资质成长修正 | [道侣关系](#道侣关系) |
| `战斗/*.json` | 行动、伤害、构筑和状态反应 | [战斗/说明.md](战斗/说明.md) |

## 依赖方向

```text
定义 -> 规则 -> 内容实例/运行实例
```

规则可以引用定义中的属性、资源和机制编号，但不能反向定义新属性、新事件或新内容实体。内容可以选择使用哪条成长规则，但不能复制一份规则后偷偷分叉。

## 道侣关系

`道侣.json` 与世界道侣实体的关系是：

```text
世界道侣实体
  + 道侣.json 的好感和同行规则
  + 成长/修士.json
  + 定义/战斗/属性.json 默认值
  -> 未来持久化道侣实例
```

`同行构筑` 只声明槽位数量，不提供功法、附魔和宝石候选池。角色候选池必须以后单独用池引用定义。

## 当前执行状态

战斗规则已由战斗核心执行。初始、成长、道侣和修行规则目前被 `GameContent` 加载，但旧玩法服务已删除，因此它们只是后续业务重建的正式输入，不代表当前已有完整玩法。
