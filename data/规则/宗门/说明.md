# 宗门规则

宗门第一阶段只管理宗门主体、成员关系、邀请和地表入口。创建时取宗主当前地表 `xy` 作为唯一入口，并生成一个独立洞天编号；洞天内部不占用世界地图格，也不修改地点、道路、地形或地势 JSON。

宗门主体、成员归属和入口分别保存为共享实体、共享成员和共享位置。三者必须与相关玩家邀请状态在同一数据库事务内改变。每个玩家同一时间只能属于一个宗门，同一地表入口只能属于一个宗门，宗门名称全界唯一。

成员总数当前不设上限。正式职位只有宗主、长老和弟子：新入宗门者为弟子，宗主可以任免长老；长老与宗主共同处理邀请、逐出弟子、宗门公共资产和日常生产，只有宗主可以任免长老、转让宗主与解散宗门。宗主转让后成为长老。

宗门同行由宗主使用`宗门同行 召集`开启，本宗同处成员使用`宗门同行 加入`主动加入，不逐人生成邀请。同行最多十五名玩家，宗主固定首位；行路、探险、闭关、采药和采矿统一读取当前有效行动组。宗门成员关系和玩家队伍关系都可以保留，但同一时刻只有宗门同行或玩家队伍中的一方实际参与行动。

## 宗门公共空间

宗门公共资源分为三个互不混用的空间：

```text
灵藏   -> 灵植、灵矿、兽宝和宗门灵石余额
万珍殿 -> 丹药、真意、气机、器律和阵法成品
藏经阁 -> 本宗成员个人道藏中的功法借阅索引
```

灵藏只接收基础材料和灵石。基础材料按`编号 + 品级`堆叠，灵石单独保存为宗门公共余额；已捐献内容不能自由取回。万珍殿只保存成品，所有成员可以存入，宗主和长老可以按目标成员发放，发放必须在同一事务内完成成品扣除和个人资产增加。

黄、玄、地、天阵法按`阵法编号 + 品级`堆叠。圣品阵法保存为独立实例，必须保留阵法编号、实际投入的灵植/灵矿/兽宝和实例编号，不保存最终计算数值；使用时按阵法 JSON 和真实投入重新计算，正式使用后消耗该实例。

藏经阁只作用于玩家人物，不作用于道侣。借阅时从本宗成员个人道藏按功法编号去重并取最高品级，写入人物的借阅构筑；借阅不转移功法所有权、不消耗资源。借阅功法离开藏经阁后仍然生效，适用于地表和宗门洞天的正式玩法；玩家退出、被逐出或宗门解散时，借阅构筑清除并恢复个人功法构筑。

## 洞天生产设施

宗门洞天固定拥有百炼堂、丹鼎阁和演阵台，不建设等级树。每次炼制按器阶或品级从宗门灵藏扣除灵石；个人炼制使用个人纳戒材料，产出进入个人资产，宗门炼制使用宗门灵藏材料，产出进入万珍殿，两条材料路径禁止混用。宗主和长老可使用两条路径并炼制圣品，弟子只能使用个人材料且不能炼制圣品。
