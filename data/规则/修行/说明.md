# 修行规则关系说明

本目录只保存闭关和探险的通用时间、轮次及阈值，不保存玩家状态、地点内容或奖励实例。

## 闭关

`闭关.json` 提供：持续时间、每轮时间、每轮经验、感悟功法概率和圆满状态清理开关。

它与其他 JSON 的预期关系：

```text
地点.可用功能 包含“闭关”
-> 使用 闭关.json 计算完成轮次
-> 人物经验交给 成长/修士.json
-> 感悟结果应从单独配置的功法池抽取
```

当前没有角色功法池，不能把 `内容/物品/功法` 的全部分类文件直接当成闭关候选池。

## 探险

`探险.json` 提供：持续时间、轮次、最多轮数、单场战斗行动上限和自动用药阈值。

```text
地点.可用功能 包含“探险”
-> 展开地点.敌人池
-> 生成敌人战斗快照
-> BattleEngine 使用战斗行动上限
-> 胜利后按敌人掉落和交锋所得结算
```

地点、敌人和掉落关系详见 `内容/世界/说明.md`。

## 当前状态

这些 JSON 会被 `GameContent` 加载，但闭关和探险业务服务已经删除。后续实现必须以本目录和世界内容为输入，不得恢复旧服务中的硬编码流程。

## 修改检查

- `持续秒数` 应能被 `每轮秒数` 合理分段。
- 探险 `最多轮数` 与持续时间的关系必须明确，不能由代码自行猜测。
- 改行动上限时同步评估战斗终局和战报体积。
- 改自动用药阈值时必须由未来物品使用协议明确消费哪类丹药。
