# 人物初始规则关系说明

`人物.json` 只描述“创建一个新人物时写入哪些初始事实”，不保存任何玩家实例。

## 组合顺序

```text
定义/战斗/属性.json 的全部默认值
-> 覆盖 人物.json.属性覆盖
-> 按 人物.json.资源 设置血气、精神和护盾
-> 按 人物.json.物品 写入初始物品编号与数量
-> 采用 成长/修士.json 作为后续成长规则
```

`资源` 中的 `"上限"` 表示读取 `定义/战斗/资源.json` 指向的上限属性。初始物品使用六位实体编号，必须能在 `内容/物品` 的普通物品索引中找到。

## 与其他 JSON 的关系

| 字段 | 关联数据 |
| --- | --- |
| `角色类型`、`成长规则` | `规则/成长/修士.json` |
| `属性覆盖` | `定义/战斗/属性.json` |
| `资源` | `定义/战斗/资源.json` |
| `物品[].编号` | `内容/物品/丹药` 或其他普通物品实体 |
| `等级/经验` | `规则/成长/修士.json` 的等级与经验规则 |

初始物品目前没有品级字段。后续重建人物创建时必须明确初始物品品级来源，不能由代码静默补一个未声明品级。

## 修改检查

- 增加属性覆盖前确认属性已经登记。
- 增加初始物品前确认编号存在、类别可入纳戒且数量为正。
- 修改成长规则名时同步修改对应规则文件或注册关系。
- 当前没有人物创建业务，不能通过修改 Python 默认值替代此文件。
