# 阵法规则关系说明

本目录只保存所有阵法共用的炼制和数值计算规则，不保存具体阵法，也不决定阵法在哪里开放。

```text
内容/阵法/阵法.json
  + 规则/阵法/炼制.json
  + 兽宝、灵矿、灵植的实际投入数量
  -> 未来阵法微服务生成一次性阵法实例
  -> 战斗建立时固化本场宏观数值快照
```

`炼制.json` 规定三类材料与阵基、阵眼、节点的对应关系，以及黄、玄、地、天固定投入和圣品无上限投入的共同公式。规则只读取材料类别、品级和数量，不解释某件材料的名称、药性、铸脉、掉落地点或战斗能力。

每座阵法的身份、五品配置和三类圣品权重属于 `内容/阵法/阵法.json`。地点以后只引用阵法编号；阵法实例保存阵法编号、品级和真实投入，不复制规则正文与最终计算结果。

## 当前状态

阵法规则与 46 座阵法目前都能被 JSON 微服务加载、编号校验和建立索引，但尚无阵法炼制或战斗执行微服务。当前代码不得把“已加载”视为“已可使用”，也不得在其他服务中临时解释阵法 JSON。
