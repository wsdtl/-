# 行路规则关系说明

本目录只负责从全境路网自动选出最合适的行程并生成结构化行程事实，不保存具体道路、玩家状态或展示文本。

## `行程.json`

```text
起点与终点
-> 展开地图登记的113条道路
-> 按逐格坐标读取地势高度
-> 计算每条候选行程的距离、升降和折算路程
-> 依次比较折算路程、道路段数、水平距离
-> 取得唯一最优行程
-> 交给展示/行程.json 生成行程叙事
```

玩家只选择目的地，不选择道路。所有已登记地点必须处于同一连通路网；找不到路线属于数据错误，不是人物境界不足。

## 境界边界

境界以后可以改变赶路方式、行程速度和展示措辞，但不能改变目的地可达性，也不能排除任何道路。剧情封锁、阵法阻断或战争封锁需要未来独立内容明确声明，不能借海拔或境界自动产生。

## 修改检查

- `道路折算倍率` 必须与地图登记的道路文件一一对应。
- 自动选路始终由规则完成，聊天指令不暴露逐段道路选择。
- 地势、道路或折算倍率改变后，必须重新校验全境连通和最优路线。
- 行程事实只描述已经选出的路线，展示层不能反向改变选路结果。
- 当前只完成JSON，移动执行器与行程文本生成器尚未实现。
